# Pipeline

## 1. Primer pipeline

Executa:

```powershell
Get-Service
```

Ara executa:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Quina diferència observes entre les dues sortides?

La primera sortida mostra els serveis sense ordenar específicament pel nom. La segona mostra els serveis ordenats alfabèticament pel nom.

2. Què fa la part situada abans de `|`?

Obté les dades que després passaran pel pipeline. En aquest cas, Get-Service obté els serveis del sistema.

3. Què fa la part situada després de `|`?

Rep les dades i les ordena segons el nom amb Sort-Object Name.

4. `Sort-Object` crea els serveis o rep serveis creats per una altra ordre?

Rep els serveis que ha obtingut una altra ordre. Sort-Object no crea els serveis.

5. Quina ordre és la que genera inicialment les dades?

Get-Service

Fes ara la prova:

```powershell
Get-Service | Sort-Object Status
```

Què ha canviat?

Ara els serveis s'ordenen segons el seu estat (Status) en lloc del seu nom.

Finalment:

```powershell
Get-Service | Sort-Object Status -Descending
```

Explica amb les teves paraules què ha fet el pipeline.

El pipeline primer obté els serveis amb Get-Service i després els passa a Sort-Object, que els ordena segons el seu estat. Amb -Descending, l'ordre es mostra de manera descendent.

## 2. El mateix problema sense pipeline

Executa:

```powershell
$serveis = Get-Service
```

Ara:

```powershell
$serveis
```

I després:

```powershell
$serveis | Sort-Object Name
```

Compara-ho amb:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Obtenen el mateix resultat?

Sí, obtenen el mateix resultat, perquè en els dos casos s'obtenen els serveis i s'ordenen pel nom.

2. Quina diferència hi ha entre les dues formes de treballar?

En el primer cas, primer guardem els serveis en una variable i després els ordenem. En el segon cas, Get-Service envia directament els serveis a Sort-Object mitjançant el pipeline.

3. En quin cas s'ha guardat prèviament la informació en una variable?

En el cas de $serveis = Get-Service


Crea ara:

```powershell
$serveisOrdenats = Get-Service | Sort-Object Name
```

Mostra:

```powershell
$serveisOrdenats
```

Explica què conté aquesta variable.


La variable $serveisOrdenats conté tots els serveis del sistema ordenats pel seu nom.

## 3. Construir un pipeline pas a pas

Executa primer:

```powershell
Get-Process
```

Ara:

```powershell
Get-Process | Sort-Object CPU
```

Finalment:

```powershell
Get-Process |
    Sort-Object CPU |
    Select-Object -First 5
```

No continuïs fins haver observat el resultat de cada ordre.

| Pas | Ordre | Què entra? | Què surt? |
|---|---|---|---|
| 1 | `Get-Process` | No entra cap dada d'una altra ordre | Tots els processos que s'estan executant |
| 2 | `Sort-Object CPU` | Els processos obtinguts amb `Get-Process` | Els mateixos processos ordenats segons el valor de CPU |
| 3 | `Select-Object -First 5` | Els processos ordenats per CPU | Els primers 5 processos de la llista |

Explica què passaria si eliminéssim:

```powershell
Sort-Object CPU
```

del pipeline.

Si eliminem Sort-Object CPU, els processos no s'ordenen segons el consum de CPU abans de seleccionar els cinc primers.

Comprova-ho executant:

```powershell
Get-Process | Select-Object -First 5
```

Els cinc processos obtinguts són necessàriament els que consumeixen més CPU?

Explica per què.


No, els cinc processos obtinguts no són necessàriament els que consumeixen més CPU, perquè Select-Object -First 5 selecciona els cinc primers processos que rep, però no els ordena segons el consum de CPU.


## 4. Ordenar processos

Emmagatzema en una variable tots els processos que s'estan executant ordenats de **major a menor consum de CPU**.

Mostra després el contingut de la variable.

A partir de la variable anterior:

1. mostra els tres primers processos;

Get-Process | Select-Object -First 3

2. mostra els cinc primers;

Get-Process | Select-Object 
-First 5

3. mostra els deu primers.

Get-Process | Select-Object -First 10

No tornis a executar `Get-Process` per fer aquests tres apartats.

## 5. Canviar l'ordre del pipeline

Executa:

```powershell
Get-Process |
    Sort-Object CPU -Descending |
    Select-Object -First 5
```

Ara executa:

```powershell
Get-Process |
    Select-Object -First 5 |
    Sort-Object CPU -Descending
```

Respon:

1. Les dues ordres fan el mateix?

No, les dues ordres no fan el mateix.

2. Per què?

Perquè l'ordre dels cmdlets modifica el resultat. En la primera ordre, primer s'ordenen tots els processos per consum de CPU i després se seleccionen els 5 primers. En la segona, primer se seleccionen 5 processos i després aquests 5 s'ordenen per CPU.

3. Quants processos arriben a `Sort-Object` en el primer cas?

Arriben tots els processos que retorna Get-Process

4. Quants processos arriben a `Sort-Object` en el segon?

Arriben només 5 processos, perquè Select-Object -First 5 ja ha seleccionat els cinc primers abans d'arribar a Sort-Object.


Aquest exercici és important: **l'ordre dels cmdlets dins del pipeline modifica el resultat**.

## 7. Modificar progressivament una ordre

```powershell

```

```text
Mostrar només els tres elements més grans.
```

Documenta cada pas.

Per exemple:

```text
Pas 1 → obtenir elements : Get-ChildItem

Pas 2 → Get-ChildItem | Sort-Object Length

Pas 3 → Get-ChildItem | Sort-Object Length -Descending

Pas 4 → Get-ChildItem | Sort-Object Length -Descending | Select-Object -First 3
```

No escriguis directament l'ordre final.

L'objectiu és construir el pipeline **una operació cada vegada**.
