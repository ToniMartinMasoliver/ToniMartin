# Enunciat

## Objectiu

Crear l’estructura inicial d’unitats organitzatives del domini `musiccloud.local`.
## Escenari

MusicCloud ja disposa del domini:
```text
musiccloud.local
```
El servidor `SRV-AD-01` ja és controlador de domini.

Ara cal crear una estructura d’unitats organitzatives que permeti organitzar els objectes de l’empresa.
## Estructura que cal crear

Creeu l’estructura següent:
```text
musiccloud.local
└── MusicCloud
    ├── Usuaris
    │   ├── Administracio
    │   ├── Comercial
    │   ├── Desenvolupament
    │   ├── Sistemes
    │   └── Direccio
    ├── Equips
    │   ├── Clients
    │   └── Servidors
    └── Grups
```
## Part 1. Creació de la UO principal

Creeu una unitat organitzativa principal anomenada:
```text
MusicCloud
```
Aquesta UO serà el contenidor principal de l’estructura de l’empresa.

### Comanda utilitzada

Per crear la unitat organitzativa principal `MusicCloud` dins del domini `musiccloud.local`, s'ha utilitzat la següent comanda de PowerShell:

```powershell
New-ADOrganizationalUnit -Name "MusicCloud" -Path "DC=musiccloud,DC=local"
```
## Part 2. Creació de les UO de primer nivell

Dins de la UO `MusicCloud`, creeu les UO següents:
```text
Usuaris
Equips
Grups
```
### Comandes utilitzades

Per crear les unitats organitzatives de primer nivell dins de `MusicCloud`, s'han executat les següents comandes:

```powershell
New-ADOrganizationalUnit -Name "Usuaris" -Path "OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Equips" -Path "OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Grups" -Path "OU=MusicCloud,DC=musiccloud,DC=local"

## Part 3. Creació de les UO de departaments

Dins de la UO `Usuaris`, creeu les UO següents:
```text
Administracio
Comercial
Desenvolupament
Sistemes
Direccio
```
Per crear les unitats organitzatives dels departaments dins de `Usuaris`, s'han executat les següents comandes:

```powershell
New-ADOrganizationalUnit -Name "Administracio" -Path "OU=Usuaris,OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Comercial" -Path "OU=Usuaris,OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Desenvolupament" -Path "OU=Usuaris,OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Sistemes" -Path "OU=Usuaris,OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Direccio" -Path "OU=Usuaris,OU=MusicCloud,DC=musiccloud,DC=local"
```
## Part 4. Creació de les UO d’equips

Dins de la UO `Equips`, creeu les UO següents:
```text
Clients
Servidors


```

### Comandes utilitzades

Per crear les unitats organitzatives dels equips dins de `Equips`, s'han executat les següents comandes de PowerShell:

```powershell
New-ADOrganizationalUnit -Name "Clients" -Path "OU=Equips,OU=MusicCloud,DC=musiccloud,DC=local"

New-ADOrganizationalUnit -Name "Servidors" -Path "OU=Equips,OU=MusicCloud,DC=musiccloud,DC=local"
```

Aquestes unitats organitzatives permeten separar els equips clients dels servidors de l'empresa i facilitar-ne l'organització i l'administració.

## Part 5. Verificació

Executeu una consulta que mostri totes les unitats organitzatives del domini.

La sortida ha de mostrar, com a mínim, les UO creades en aquesta pràctica.

### Comanda utilitzada

Per comprovar totes les unitats organitzatives del domini `musiccloud.local`, s'ha utilitzat la següent comanda de PowerShell:

```powershell
Get-ADOrganizationalUnit -Filter * | Select-Object Name, DistinguishedName
```

Aquesta comanda mostra totes les unitats organitzatives del domini i la seva ubicació dins de l'estructura d'Active Directory.

El resultat confirma que s'han creat correctament les unitats organitzatives principals, les dels departaments i les dels equips de MusicCloud.

## Part 6. Preguntes

Responeu breument:

1. Per què és útil crear una UO principal anomenada `MusicCloud`?  
>Perquè permet agrupar tots els objectes de l'empresa dins d'una mateixa estructura i facilita l'organització i l'administració del domini.
2. Per què se separen `Usuaris`, `Equips` i `Grups`?  
>Perquè permet organitzar els diferents tipus d'objectes per separat i facilita la seva administració i gestió dins d'Active Directory.
3. Per què els departaments s’han creat dins de `Usuaris`?  
>Perquè permet classificar els usuaris segons el departament al qual pertanyen, com Administració, Comercial o Sistemes, i facilita l'aplicació de permisos i polítiques diferents.
4. Per què no és recomanable deixar tots els usuaris dins del contenidor `Users`?  
>Perquè és un contenidor predeterminat que ofereix menys possibilitats d'organització i administració mitjançant polítiques de grup. Les unitats organitzatives permeten gestionar millor els usuaris i aplicar polítiques específiques.
