# Pràctica

## Objectiu

Preparar el servidor `SRV-AD-01` i promocionar-lo com a primer controlador de domini del domini `musiccloud.local`.
## Escenari

L’empresa **MusicCloud** vol iniciar la implantació d’Active Directory Domain Services.

El servidor Windows Server que s’utilitzarà com a controlador de domini serà:
```text
SRV-AD-01
```
El domini que es crearà serà:
```text
musiccloud.local
```
Aquest servidor també proporcionarà el servei DNS del domini.

>### Comandes utilitzades

Per comprovar i configurar el servidor s'han utilitzat les comandes següents:

```powershell
hostname
Rename-Computer -NewName "SRV-AD-01"
Restart-Computer
ipconfig /all
Get-NetIPConfiguration
Get-NetAdapter
```

La comanda `hostname` permet consultar el nom del servidor. `Rename-Computer` serveix per canviar-lo i `Restart-Computer` reinicia el sistema perquè s'apliqui el canvi. Les comandes `ipconfig /all` i `Get-NetIPConfiguration` permeten consultar la configuració IP i DNS, mentre que `Get-NetAdapter` mostra els adaptadors de xarxa disponibles.

### Part 2. Instal·lació del rol AD DS

Localitzeu i utilitzeu el procediment adequat per instal·lar el rol AD DS i promocionar el servidor a controlador de domini. Documenteu breument les comandes o passos utilitzats.



### Comandes utilitzades

Per instal·lar el rol Active Directory Domain Services (AD DS) i les eines d'administració, s'ha utilitzat la comanda següent:

```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
```

La instal·lació s'ha completat correctament. El resultat ha estat `Success: True`, amb el codi de sortida `Success`, i no ha estat necessari reiniciar el servidor en aquest moment.


### Part 3. Promoció a controlador de domini
Promocioneu el servidor a controlador de domini amb les opcions següents:

| Opció                                  | Valor              |
| -------------------------------------- | ------------------ |
| Tipus d’implantació                    | Crear un nou bosc  |
| Nom del domini arrel                   | `musiccloud.local` |
| Servidor DNS                           | Sí                 |
| Catàleg global                         | Sí                 |
| Nom NetBIOS                            | `MUSICCLOUD`       |
| Controlador de domini de només lectura | No                 |
| Reinici final                          | Sí                 |
Definiu una contrasenya segura per al mode de restauració de serveis de directori.


```powershell
Install-ADDSForest `
-DomainName "musiccloud.local" `
-DomainNetbiosName "MUSICCLOUD" `
-InstallDNS
```

>S'ha executat la comanda Install-ADDSForest per crear un nou bosc amb el domini musiccloud.local. També s'ha configurat el nom NetBIOS MUSICCLOUD i s'ha instal·lat el servei DNS. La promoció s'ha iniciat correctament.

## Preguntes

Responeu breument:

1. Per què `SRV-AD-01` necessita una IP fixa?
   > Perquè els clients del domini han de poder localitzar sempre el controlador de domini i el servidor DNS a la mateixa adreça IP. Si la IP canviés, podria provocar problemes de connexió i autenticació.

2. Per què és necessari DNS en un domini Active Directory?
    >Perquè Active Directory utilitza DNS per localitzar els controladors de domini i altres serveis necessaris per al funcionament del domini.

3. Quina diferència hi ha entre instal·lar AD DS i promocionar el servidor a controlador de domini?
    >Instal·lar AD DS afegeix el rol i les eines necessàries al servidor. Promocionar-lo crea el domini i configura el servidor perquè funcioni com a controlador de domini.

4. Quin és el nom del domini creat?
    >El nom del domini creat és `musiccloud.local`.

5. Quin és el nom NetBIOS del domini?
    >El nom NetBIOS del domini és `MUSICCLOUD`.

6. Per què no és recomanable que els clients del domini utilitzin un DNS extern com a DNS principal?
   > Perquè un DNS extern no coneix els registres interns d'Active Directory. Això pot impedir que els clients trobin el controlador de domini i altres serveis necessaris per iniciar sessió i funcionar correctament.
