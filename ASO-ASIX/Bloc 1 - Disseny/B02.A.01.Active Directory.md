# Activitat: del disseny a l’arquitectura d’AD DS

# Context

MusicCloud ja ha completat el disseny lògic del seu servei de directori.  

Abans d’instal·lar Active Directory Domain Services, cal comprovar que l’alumnat identifica correctament els components que s’hauran d’implantar.  

# Identificació dels components

A partir de l’arquitectura prevista, indiqueu:

1.   Quin serà el nom del bosc.  
    >El bosc tindrà un únic domini inicial, que serà el domini de MusicCloud.
2.   Quin serà el nom del domini.  
    >El nom del domini serà musiccloud.local.
3.   Quin servidor actuarà com a controlador de domini.  
    >El servidor SRV-AD-01 serà el controlador de domini, ja que tindrà instal·lat el servei AD DS.
4.   Quin servidor proporcionarà DNS.  
    >El servidor SRV-AD-01 també proporcionarà el servei DNS per resoldre els noms del domini i localitzar els serveis d'Active Directory.
5.   Quin protocol s’utilitzarà principalment per a l’autenticació.  
    >S'utilitzarà principalment el protocol Kerberos per autenticar els usuaris del domini
6.   Quin protocol permetrà consultar els objectes.  
    >S'utilitzarà el protocol LDAP per consultar els objectes del directori, com ara els usuaris, els grups i els equips.  
7.   7. Quin servei de Windows emmagatzema i administra els objectes del domini?
    >El servei Active Directory Domain Services (AD DS) emmagatzema i administra els objectes del domini.

# Anàlisi de l’arquitectura

Responeu breument:

1.   Per què el servidor `SRV-AD-01` necessita una adreça IP fixa?
    > Perquè els clients han de poder trobar sempre el controlador de domini i el servidor DNS a la mateixa adreça IP.
2.   Per què els clients del domini han d’utilitzar un servidor DNS capaç de resoldre la zona d’Active Directory?
    > Perquè necessiten localitzar el controlador de domini i els serveis necessaris per iniciar sessió i treballar dins del domini.
3.   Què passaria si `SRV-AD-01` estigués apagat?
    > Els clients podrien tenir problemes per iniciar sessió al domini i accedir als serveis d'Active Directory. També podrien deixar de funcionar els serveis DNS que proporciona aquest servidor.
4.   Per què un únic controlador de domini és acceptable al laboratori però insuficient en una empresa real?
    > Al laboratori és suficient per aprendre i fer les pràctiques. En una empresa real, tenir un únic controlador de domini és un risc perquè, si falla, els serveis del domini poden quedar afectats. Per això és recomanable tenir més d'un controlador de domini.
5.   Per què els departaments no s’han creat com a dominis diferents?
    > Perquè tots els departaments formen part de la mateixa empresa i poden compartir un únic domini. Les unitats organitzatives (OU) i els grups permeten organitzar els usuaris i gestionar els permisos sense necessitat de crear dominis diferents.

Justifiqueu breument l’ordre escollit.  

> Primer cal preparar la xarxa del servidor i comprovar que la configuració DNS és correcta. Després s'instal·la AD DS i es crea el bosc amb el domini. Quan el domini ja funciona, es creen les unitats organitzatives, els grups i els usuaris, i s'assignen els usuaris als grups corresponents. Finalment, es comprova el funcionament del domini i s'hi uneix el client.
