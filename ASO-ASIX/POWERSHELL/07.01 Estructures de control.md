## 1. Condicional

Crea:
```powershell
$port = 443
```

```
Port HTTPS
```
si el port és `443`.

>Si canviem el valor de $port a 80, no es mostra cap missatge perquè la condició no es compleix.
## 2. if o switch

Crea:
```
$estat = 2
```
Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions. 

>Comparació: L'if comprova diferents condicions, mentre que el switch compara una variable amb diferents valors. El switch és més senzill de llegir quan hi ha moltes opcions.

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```
Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu

>El missatge només es mostra si el port és 443 i el servei està actiu, perquè s'han de complir les dues condicions.

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip? 

Proposa diferents codis de resolució.

>Primera solució:
Get-Service | Where-Object { $_.StartType -eq "Automatic" } | Measure-Object

>Segona solució:
(Get-Service | Where-Object { $_.StartType -eq "Automatic" }).Count

>Tercera solució:
$serveis = Get-Service
$automatics = $serveis | Where-Object { $_.StartType -eq "Automatic" }
$automatics.Count


Aquestes ordres permeten comptar els serveis configurats amb inici automàtic. El nombre exacte depèn del teu ordinador.

# Conclusions

Explica amb les teves paraules:

1. Què representa la variable `$servei` en:
```powershell
$serveis = Get-Service
foreach ($servei in $serveis) {
    ...
}
```
>Representa cada servei individual de la llista $serveis. El foreach recorre la llista i agafa els serveis un per un.

2. Quina diferència hi ha entre `foreach` i `ForEach-Object`?
>foreach és una estructura que recorre una col·lecció d'elements. ForEach-Object és una ordre que processa els objectes que rep a través d'un pipeline.

3. Què representa `$_` dins de `ForEach-Object`?

>Representa l'objecte actual que s'està processant. Per exemple, si estem recorrent serveis, $_ representa el servei que s'està tractant en aquell moment.
